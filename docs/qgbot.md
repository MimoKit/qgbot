# qgbot

> QQ 官方机器人（QQ 开放平台）的 **Markdown 消息构造 SDK**。把平台那套 markdown 语法、键盘 JSON 和图片上传流程收敛成可组合的 Python API，插件不必再手拼字符串字面量。
>
> 纯标准库，零运行时依赖，不绑定任何 bot 框架。

## 它解决什么

QQ 官方机器人的 markdown 跟标准 markdown 不是一回事。图片尺寸写在 alt 文本里（`![x #200px #300px](url)`）、分隔线是 `***` 不是 `---`、下划线是 `__` 不是 `<u>`、连续换行会被合并所以要多空一行得插零宽空格、@ 用户的标签从 `<@id>` 换成了 `<qqbot-at-user id="" />`。这些细节散在文档各处，每个插件都要重复踩一遍。

按钮同理：平台要的是一段嵌套 JSON（`content.rows[].buttons[].render_data/action`），`action.type` 区分链接 / 回调 / 指令 / 订阅，`permission.type` 区分所有人 / 管理员 / 指定用户 / 指定身份组。手写容易把 `type` 和 `style` 搞混。

图片还有第三层问题：markdown 里的图必须是公网 URL，平台自己去拉；插件渲染出来的卡片只存在本地磁盘。官方图库的上传是**三步预签名流程**——先声明文件元信息拿预签名地址，PUT 原始字节到对象存储，再回传 ETag 里的 MD5 收尾——而不是一次 multipart 提交。

qgbot 把这三块分别封成 `md`、`keyboard`、`media`，再加一个 `message` 负责组装发送用的 payload。

## 覆盖范围

- **`md`** —— 标题、六种文字样式、行内链接与自动链接、带尺寸的图片、有序 / 无序列表（含 4 空格的二级缩进）、引用块、分隔线、多空行、正文内联指令按钮（`cmd_input` / `cmd_enter`）、@ 用户与 @ 全体、频道子频道跳转与系统表情。
- **`keyboard`** —— 链接、回调、指令三类按钮，权限限定，按行切分，字号设置。
- **`media`** —— 图库上传的完整三步流程，含签名计算、错误码映射、列表解析与删除。
- **`message`** —— markdown 正文与键盘合成发送 body，带 `msg_id` / `msg_seq` 的被动回复字段。

## 边界

**不做网络请求。** 素材上传只算 MD5 / SHA1、组装请求体、解析响应，实际的 HTTP 由调用方注入的 `Transport` 完成。这样 SDK 既不用绑定 httpx / aiohttp / requests 里的任何一个，调用方也能复用自己框架的连接池、代理和重试策略；测试也不必起 mock server。

**不管鉴权。** AccessToken 的获取与刷新属于调用方。SDK 产出的 payload 里不含凭据。

**不做语法校验。** 平台的硬限制（标题只支持两级、键盘最多 5 行、图片 10 MB、单图库最多 100 张、`cmd_input` 的 text 与 show 各 100 字符）以常量和文档注释的形式暴露，但 SDK 不主动改写用户内容。两处例外：标题层级会被夹到合法范围（传 3 得到 2，避免用户以为有三级标题），键盘超过 5 行会被截断（平台本身就不渲染，抛错反而让整条消息发不出去）。

**不解析已有 markdown。** 只有构造，没有反向解析。

## 平台约束备忘

写进实现注释里的那些坑：

- 图片尺寸必须显式给出。不给就按原图铺满，一张 1080×1920 的立绘会把消息撑满整屏，所以 `image()` 收到非正数尺寸直接抛错，逼调用方做决定。
- `cmd_enter`（点击直接发送）在群聊与文字子频道都不可用，只有单聊有效。
- 群聊里 @ 用户只在 markdown 消息中生效，纯文本不支持；@全体要求机器人是群管理员，且**每个群每个自然日只能用一次**，超出后平台拒收整条消息而不只是忽略该标签。
- `@` 的 id 含义随场景变化：群聊要成员的 `member_openid`，文字子频道要用户的 `user_openid`。
- 上传时 PUT 的 `Content-Type` 必须与 prepare 阶段声明的一致，否则对象存储直接 403；`ETag` 带引号，要剥掉才能和白名单里声明的 MD5 对上。
- 图库链接绑定所属机器人，别的 bot 用同一个 URL 会收到 40035010。

## 目录

```
qgbot/
├── qgbot/
│   ├── md.py          markdown 语法构造
│   ├── keyboard.py    按钮与键盘
```
